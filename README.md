Topics include:

* GPIO

* Interrupts
* Register manipulation
* Memory-mapped I/O

### 🧮 NAND2Tetris Computer Architecture

Implementing and studying the NAND2Tetris computer architecture through multiple approaches.

* NAND2Tetris HDL
* SystemVerilog

* Logisim Evolution circuit designs
* Notes and documentation covering computer architecture concepts

```text

↓

Arithmetic Logic

CPU

Computer
```
