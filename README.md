Exploring firmware development for the **ATmega328P** using C with direct hardware register manipulation and low-level peripheral control.

The goal is to understand how microcontrollers work beneath higher-level frameworks and libraries.

Topics include:

* GPIO
* Timers
* Interrupts
* Register manipulation
* Memory-mapped I/O

### 🧮 NAND2Tetris Computer Architecture

Implementing and studying the NAND2Tetris computer architecture through multiple approaches.

* NAND2Tetris HDL
* SystemVerilog
* Icarus Verilog
* Logisim Evolution circuit designs
* Notes and documentation covering computer architecture concepts

I'm using this project to understand how simple logic gates can scale into increasingly complex components such as:

```text
NAND Gates
↓
Logic Gates
↓
Arithmetic Logic
↓
Memory
↓
CPU
↓
Computer
```
